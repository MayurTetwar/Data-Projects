# 🍫 Chocolate Sales Dashboard – Power BI

A complete end-to-end **Power BI dashboard** built to analyze sales performance, shipments, costs, and profitability for a chocolate manufacturing company.  
This project includes **20+ DAX measures**, custom icons, dynamic colors, and a clean professional UI.

---

## 📌 **Project Overview**

This dashboard provides a comprehensive view of:

- **Total Sales**
- **Total Boxes Sold**
- **Total Shipments**
- **Total Cost & Profit**
- **Profit %**
- **Salesperson Performance**
- **Country-wise Insights**
- **Monthly Trends**
- **Shipment Analysis**

The goal of the report is to help stakeholders quickly understand business growth, cost patterns, and top-performing salespersons.

## 🎯 **Insights Generated**

- Sales increased by **11.3%** in the last tracked month  
- Shipment sizes are highest between the 0–200 range

- Majority of shipments originate from key regions like USA & Canada  
- Profit margins remain consistent across months
